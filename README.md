# Good morning, world!

**Автор:** Daryna Kurdysh · **2026**

Музыкальный веб-инструмент о пробуждении: от мягкого состояния **Sleep** к мелодичному **Wake** и энергичному **Move**. Вся музыка синтезируется в браузере, без готовых аудиозаписей.

**Работающий сайт:** https://dkurdysh.github.io/good-morning-world-sintizator/

## Возможности

- **Power** запускает и останавливает живую композицию (108 BPM, до мажор).
- Два независимых голоса: **Lead synth** и **Bass synth**; каждый имеет собственные Filter → Tremolo → Delay → Reverb → Channel цепочки и стереопанораму.
- Форма волны: **sine / square / sawtooth / triangle**.
- Слайдеры: **volume / portamento / detune / phase / filter / attack**.
- Три сцены: **Sleep / Wake / Move**; переходы синхронизированы с началом следующего такта.
- **Sound Character:** Soft / Bright / Sharp — выраженное изменение тембра, фильтра и атаки.
- **Effects:** включение Delay / Reverb / Tremolo, можно сочетать.
- **Rhythm lab:** восемь шагов для Kick / Snare / Hat, можно изменять во время звучания.
- **Живая осциллограмма** у каждого голоса. Когда звук выключен, показывается схема выбранной волны.

## Запуск в VS Code

```bash
npm install --registry=https://registry.npmjs.org/
npm run dev
```

Открыть ссылку Vite, обычно `http://localhost:5173/`. **Нажать Power**, чтобы разблокировать аудио в Safari/Chrome. Не запускать React-проект через Live Server или открытием `index.html` как обычного файла.

## Архитектура

- `src/App.jsx` — React-компоненты и состояние элементов.
- `src/style.css` — визуальная система по авторскому макету.
- `src/music.js` — ноты и варианты авторской композиции Sleep / Wake / Move.
- `src/audio.js` — Tone.js, аудиоканалы, цепочки эффектов, драм-машина и синхронизация.
- `.github/workflows/deploy.yml` — публикация в GitHub Pages.

### Звуковой тракт

```text
Lead MonoSynth -> Filter -> Tremolo -> FeedbackDelay -> Reverb -> Channel (L) ─┐
Bass MonoSynth -> Filter -> Tremolo -> FeedbackDelay -> Reverb -> Channel (R) ─┼─> Master -> output
Kick / Snare / Hat --------------------------------------> Drum Channel ──────┘
```

### Примечание по макету

В присланном референсе второй раз повторяется `phase`. В итоговой версии нижняя левая ручка подписана **filter**, так как управляет частотным фильтром и обеспечивает слышимое изменение тембра. У первого голоса индекс 1, у второго — 2.
