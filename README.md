О проекте
Good morning, world! — музыкальный инструмент о пробуждении. Пользователь постепенно меняет звучание композиции: от спокойного Sleep через мелодичный Wake к энергичному Move. Мелодия создаётся в браузере, а не воспроизводится из готовой аудиозаписи.

Концепция проекта — «Your morning. Your music.» У каждого утра может быть собственное звучание: его можно менять с помощью параметров синтеза, эффектов и драм-машины.
Возможности
- Lead synth — основная мелодия; Bass synth — басовая партия. Голоса работают независимо и разведены в стереопанораме.
- Volume, Portamento, Type, Detune, Phase, Filter, Attack — настройки звучания каждого инструмента.
- Sine, Square, Sawtooth, Triangle — четыре формы звуковой волны.
- Sleep / Wake / Move — три музыкальных состояния, которые меняют мелодический и басовый рисунок. Переключение происходит на границе такта.
- Sound Character: Soft / Bright / Sharp — изменение характера звука.
- Effects: Delay / Reverb / Tremolo — включаемые эффекты.
- Rhythm Lab — драм-машина с восьмишаговой сеткой для Kick, Snare и Hat.
- Осциллограммы — визуализация звуковых волн двух синтезаторов.
Музыкальная основа: до мажор, 108 BPM. Основная тема развивается от мягкого вступления до более насыщенного ритмического звучания.
Технологии
React · JavaScript · CSS · Vite · Tone.js · Web Audio API · GitHub Pages

Использование ChatGPT
При разработке проекта использовался ChatGPT (OpenAI) как помощник по программированию и настройке музыкального инструмента: для реализации интерфейса на React, работы с Tone.js, построения звуковых цепочек, музыкальных состояний и драм-машины, а также для поиска и исправления ошибок.

Обобщённый промпт проекта (составлен по переписке, не дословная цитата):
Создай веб-синтезатор Good morning, world! на React и Tone.js по моему авторскому макету. Сохрани визуальную систему: серый фон, белые карточки, чёрные элементы и кислотно-жёлтые акценты. Реализуй два независимых голоса — Lead synth и Bass synth — с отдельными цепочками эффектов и визуализацией волны. Добавь управление Volume, Portamento, Type, Detune, Phase, Filter и Attack, музыкальные состояния Sleep/Wake/Move, режимы Sound Character, эффекты Delay/Reverb/Tremolo и восьмишаговую драм-машину Kick/Snare/Hat. Все элементы должны влиять на звучание во время исполнения. Сделай адаптивный интерфейс и подготовь проект для публикации на GitHub Pages.
